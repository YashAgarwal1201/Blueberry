# Express CRUD Learning

This is a basic Express.js setup to help you learn CRUD operations.

## Getting Started

1. Install dependencies:
   ```sh
   npm install
   ```
2. Start the server:
   ```sh
   node index.js
   ```
3. Open [http://localhost:8100](http://localhost:8100) in your browser.

## Next Steps

- Implement CRUD endpoints in `index.js`.
- Use tools like Postman or curl to test your API.

## Project Structure

- `index.js`: Main server file
